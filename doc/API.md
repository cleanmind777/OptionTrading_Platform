# API Documentation

Base URL (local): `http://localhost:8000/api/v1`

Interactive docs (Swagger): [http://localhost:8000/docs](http://localhost:8000/docs)

## Endpoints overview

| Area | Prefix | Description |
|------|--------|-------------|
| Auth | `/auth` | Login, register, token refresh, OAuth |
| Users | `/users` | User profile and management |
| Strategies | `/strategies` | Strategy CRUD and listing |
| Backtest | `/backtest` | Run and retrieve backtest results |
| Bots | `/bot` | Trading bot config and control |
| Demo | `/demo` | Demo account and demo trading |
| Live trade | `/live_trade` | Live trading operations |
| Schwab | `/schwab` | Schwab brokerage integration |
